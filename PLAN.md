# BRATCODE v1.0 — Полное ТЗ и Архитектурный План Реализации

## 1. Контекст и исходная точка

1. **`bratcode` (`github.com/houlwave/bratcode`)** — терминальный TUI-клиент в эстетике альбома `brat` (чёрный экран, `brat green #8ACE00`, `demure pink #F3B6D6`, смена сторон пластинки `Side A / Side B` по `Tab`, нумерация сообщений как треков `01, 02...`, эквалайзер `▁▂▃▅▇`, командная палитра `Ctrl+P` / `/`). До этого момента внутри `src/app.js` стояла демо-заглушка (`stub reply`).
2. **Эталонная механика песочницы + фонового чата**:
   - ИИ-модель в режиме фонового чата (`ai_chat` с веб-доступом) получает ссылку на `/agent/<token>/help`, заходит туда и управляет окружением обычными `GET`-запросами (`/read`, `/write`, `/edit`, `/exec`, `/look`, `/tg_*`, `/osascript` и др.) **внутри одного непрерывного запроса** — читает результат прямо из ответа на URL и идёт дальше.
   - Очередь входящих сообщений (`inbox`) позволяет дописывать промпты прямо во время работы модели: сервер отдаёт их хвостом в ответе на очередной `GET`-запрос (`>>> NEW MESSAGE FROM THE USER`), поэтому не нужно тратить новый запрос и новые лимиты аккаунтов.

## 2. Все собранные требования пользователя

1. **Никаких правок в старом проекте:** всё живёт исключительно внутри репозитория `houlwave/bratcode`.
2. **Установка и запуск в 1 команду (macOS-first):**
   - Установка одной командой из GitHub (`curl -fsSL https://raw.githubusercontent.com/houlwave/bratcode/main/install.sh | bash`).
   - Запуск одной командой `bratcode` в терминале без ручного поднятия серверов, туннелей или браузеров — все служебные процессы полностью невидимые.
3. **Компьютер = Песочница (1 запрос = полноценный агент):**
   - Локальный сервер команд на Mac с временным защищённым HTTPS-адресом и страницей гайда `/agent/<token>/help`.
   - Выполнение команд через `GET` прямо на компьютере пользователя и возврат результатов в тот же URL, чтобы `ai_chat` видел все изменения в реальном времени.
4. **Дописывание промптов на лету в том же запросе:**
   - При отправке сообщения во время активной работы агента текст не порождает новый запрос, а падает в `inbox` песочницы и мгновенно доставляется модели в её следующем шаге.
5. **Личный Telegram внутри `bratcode`:**
   - Привязка личного аккаунта Telegram прямо в TUI (QR-код полублоками `▀` в терминале + поддержка 2FA).
   - Полная работа с переписками и контактами от имени пользователя: найти чат семьи, прочитать и проанализировать планы на выходные, найти контакт мамы и написать ей сообщение.
6. **Пул сессий/аккаунтов и живой баланс токенов:**
   - Автоматический подбор доступного аккаунта с открытой моделью и положительным балансом + бесшовное переключение при исчерпании баланса.
   - **Обновление баланса при начале набора промпта** (как только начинаешь печатать в поле ввода).
   - **Обновление баланса сразу после выполнения каждого запроса**.
7. **Регулярные промежуточные пуши в GitHub (`houlwave/bratcode`)** по мере готовности этапов, чтобы исключить потерю работы.

## 3. Поэтапный план реализации (Этапы 1–6)

### Этап 1. Каркас данных, зависимости и 1-командный установщик под macOS
- Разделение директории кода (`~/.bratcode`) и директории состояния (`~/.bratcode-data`, права `0700`), чтобы обновление репозитория никогда не стирало сессию Telegram, пул аккаунтов и бэкапы.
- Модуль `src/paths.js` — пути macOS (`Homebrew`, системный Chrome/Brave/Chromium, хранилища JSON с атомарной записью).
- Обновление `package.json` и `install.sh` (тихая установка пакетов, проверка браузера, автозагрузка `cloudflared` под `arm64`/`x64` в `~/.bratcode-data/bin`, симлинк `~/.local/bin/bratcode` и `PATH` в `~/.zshrc`).

### Этап 2. Локальная песочница ПК + `/help` + Невидимый URL (`src/sandbox/`)
- HTTP-сервер на `127.0.0.1:<free_port>` с криптостойким токеном `/agent/<token>/<cmd>`.
- Фоновый менеджер невидимого HTTPS-туннеля (`src/sandbox/tunnel.js`) с автопереподключением.
- Живая шина событий и очередь `inbox` для доставки доп. промптов без повторной отправки запроса (`src/sandbox/events.js`).
- Страница документации `/agent/<token>/help` (`src/sandbox/help.js`) с топиками (`telegram`, `mac`, `files`, `edit`, `code`, `batch`, `browser`, `vision`).
- Полный инструментарий хоста:
  - Файлы по всему диску Mac (`~/Desktop`, `~/Downloads`, проект) + автоматический бэкап и откат `/undo` (`src/sandbox/backups.js`).
  - Атомарные правки и навигация по коду (`edit.js`, `code.js`: `read` с SHA, `write`, `edit`, `multiedit`, `patch`, `grep`, `glob`, `tree`, `outline`, `symbols`, `refs`, `diagnostics`, `batch`).
  - Терминал (`exec`, фоновые сервисы `start`/`logs`/`ps`/`stop`).
  - Управление macOS (`src/sandbox/macos.js`: `sysinfo`, `osascript` для Calendar/Notes/Reminders/Finder/Music, `screen` со скриншотом экрана, `clipboard`, `open_app`, `notify`).
  - Браузер и компьютерное зрение (`browser.js`, `eyes.js`, `vision.js`, `lab.js`).

### Этап 3. Личный Telegram (MTProto / GramJS) (`src/telegram/`)
- Клиент `src/telegram/client.js` с сохранением `StringSession` в `~/.bratcode-data/telegram.json` (`0600`).
- Авторизация по QR-коду прямо в буфере терминала `bratcode` (отрисовка матрицы полублоками `▀`) + ввод облачного пароля 2FA при необходимости.
- Команды агента:
  - `tg_status` — проверка статуса и имени профиля.
  - `tg_dialogs` — список личных переписок и групп с ID и непрочитанными сообщениями.
  - `tg_search` — поиск контактов и чатов по имени (`Мама`, `Семья`), `@username` или номеру.
  - `tg_read` — чтение истории чата с авторами, датами/днями недели, текстами и ответами.
  - `tg_find_msg` — поиск конкретных обсуждений и планов по ключевым словам во всех чатах или внутри выбранного чата.
  - `tg_send` — отправка сообщений от лица пользователя (с автоисполнением на `Side A brat` и подтверждением в 1 клик `Enter` на `Side B demure`).

### Этап 4. Невидимый пул аккаунтов, фоновый `ai_chat` и живой баланс (`src/pool/`)
- Изолированные браузерные профили и куки в `~/.bratcode-data/partitions/account_<id>`, учёт лимитов моделей (`model-access.js`) и актуального каталога моделей (`models.js`).
- Стриминговый SSE-клиент `ai_chat` (`sse-parser.js`, `protocol.js`, `runner.js`) с предзаготовкой токенов в скрытом headless-контексте и бесшовным переключением аккаунта при нулевом балансе.
- Два обязательных триггера баланса:
  1. **При начале ввода промпта** в `bratcode` — фоновое обновление баланса всех активных аккаунтов волнами.
  2. **Сразу после завершения каждого запроса** — мгновенное обновление баланса использованного аккаунта.
- Поддержка добавления аккаунтов прямо из `bratcode` (`/accounts` → вход в окне или импорт готовых профилей с Mac в режиме чтения без изменения сторонних папок).

### Этап 5. Интеграция в TUI `bratcode` (`src/app.js`)
- Сохранение чистого стиля пластинки `brat`:
  - Живые шаги песочницы в реальном времени под треком + эквалайзер `▁▂▃▅▇`.
  - Ввод во время работы агента отправляет доп. инструкции напрямую в `inbox` текущего запуска (`+ ...`).
  - Ненавязчивая строка статуса снизу: директория/ветка, статус туннеля песочницы, индикатор `tg` и актуальный баланс токенов.
  - Интерактивные оверлеи в стиле палитры: `/tg` (QR-привязка), `/accounts` (управление пулом и логин), `/balance` (ручное обновление), `/undo` (откат файлов), плюс карточка подтверждения чувствительных действий для режима `Side B demure`.

### Этап 6. Автотесты, документация и финальный деплой в GitHub
- Набор автотестов `tests/run-all.js` (все команды песочницы, доставка доп. промптов через `inbox`, бэкапы `/undo`, логика баланса/ротации, рендер экранов TUI и QR).
- Обновление `README.md` и пуш финальной версии в `https://github.com/houlwave/bratcode`.
